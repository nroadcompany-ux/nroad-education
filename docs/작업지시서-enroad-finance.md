## 2. 작업 범위

### 2-1. 그대로 가져올 계산기 (18종 중 사내 유용 항목)
- `loan` 대출계산 / `loanCompare` 대출비교 — 사업자 대출 검토
- `savings` `deposit` `targetAmount` — 사내 자금 운용
- `netSalary` 실수령 / `salaryIncrease` 연봉인상률 / `severance` 퇴직금 — **급여/인사 업무 핵심**
- `exchange` 환율 — 해외 거래/정산
- `pyeong` 평수 / `memo` 계산노트 / `basic` 기본계산기 — 범용
- (선택) `profit` `profitGlobal` `avgPrice` `feeCheck` `feeRate` `bestRate` — 투자/여유자금

### 2-2. 사내 특화로 **추가**할 계산기 (신규 — 같은 패턴으로 구현)

| key | 계산기명 | 로직 |
|---|---|---|
| `vat` | 부가세계산 | 공급가↔합계 (세액 = 공급가 × 10%) |
| `withholding` | 원천징수(3.3%) | 사업소득 지급액 → 세액 3.3% 공제 후 실지급 |
| `margin` | 마진/원가계산 | 원가·판매가 → 마진율·마진액, 또는 목표마진→판매가 역산 |
| `breakeven` | 손익분기점 | 고정비/(1-변동비율) = 손익분기 매출 |
| `insurance4` | 4대보험 계산 | 사업주/근로자 부담 분리(국민연금·건강·고용·산재) |
| `corpTax` | 간이 법인세 | 과표 구간별 세율(2억 이하 9% / 초과 19% 등) 근사 |

> 위 신규 계산기는 베이스의 `F()`/`card()`/`SEG()` 헬퍼 + `CALCS.<id> = { body, init }` 패턴을 그대로 따라 추가하면 됩니다.

### 2-3. 제거/변경
- ❌ **PayPlay CTA 배너 제거** (사내 시스템엔 불필요)
- ❌ 외부 마케팅 카피("매장 시작하기" 등) 제거

## 3. 신규 계산기 검증 수식 (사내용)

```js
// 부가세 (일반과세 10%)
세액 = 공급가액 * 0.1;            // 공급가 → 합계
공급가액 = 합계 / 1.1;            // 합계 → 공급가 (역산)
세액 = 합계 - 공급가액;

// 원천징수 3.3% (사업소득)
소득세 = 지급액 * 0.03;          // 3%
지방소득세 = 소득세 * 0.1;       // 0.3%
실지급액 = 지급액 - 소득세 - 지방소득세;   // = 지급액 * 0.967

// 마진
마진액 = 판매가 - 원가;
마진율 = 마진액 / 판매가 * 100;  // (판매가 대비) — 사내 기준 통일 필요
목표판매가 = 원가 / (1 - 목표마진율/100);  // 역산

// 손익분기점(BEP)
BEP매출 = 고정비 / (1 - 변동비율);         // 변동비율 = 변동비/매출
BEP수량 = 고정비 / (판매단가 - 단위변동비);

// 4대보험 (2026 요율 기준 — 실제 요율 확인 후 상수화)
국민연금   = 기준소득월액 * 0.045 (근로자) / 0.045 (사업주)   // 상한 확인
건강보험   = 보수월액 * 0.03545 (각각)
장기요양   = 건강보험료 * 0.1281
고용보험   = 보수월액 * 0.009 (근로자) + 사업주 추가(규모별)
산재보험   = 보수월액 * 업종별요율 (사업주 전액)

// 간이 법인세 (2026 추정 — 확정 세율로 교체)
과표 ≤ 2억:        세액 = 과표 * 0.09
2억 < 과표 ≤ 200억: 세액 = 1,800만 + (과표-2억) * 0.19
// (지방소득세 10% 별도)
```

> ⚠️ 세율·요율은 **연도별 변동**되므로 코드 상단에 상수로 분리하고, 적용연도를 주석에 명시할 것.
